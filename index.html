Firebase 資料庫權限遭到拒絕 (Permission Denied)

            

            

                
您的 Firebase Firestore 資料庫目前設定為「拒絕讀寫」，因此網頁無法儲存資料。請依照以下步驟修改安全規則：

                
    
                    
  1. 前往 Firebase 控制台 並進入您的專案。
    2. 
                    
  2. 在左側選單點選 Build > Firestore Database。
    3. 
                    
  3. 切換到 Rules (規則) 頁籤。
    4. 
                    
  4. 將裡面的程式碼替換為以下內容，並點擊 Publish (發佈)：
    5. 
                

                
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

                
 修改完成後，請重新整理本網頁即可恢復雲端同步功能。（目前將暫時使用本地記憶體模式）
